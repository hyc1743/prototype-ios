# native-dev.5 回归修正

2026-10-23，用户报告 native-dev.4 从启动起黑屏且无声。两次启动日志均显示
资源就绪、guest 启动成功、新矩形细分路径被执行，音频设备回调也在持续消费队列。
第二次启动连续两段 10 秒各消费 1876 个缓冲，缺帧补零为 0。这只能证明队列
有数据，不能证明采样非静音或扬声器可听。不能继续把无声归因于缓冲耗尽。

本版优先撤回上版运行路径的变动：

- 生产构建撤回细分图元展开补丁。准备出的 native_renderer.cpp、
  native_tessellation.cpp/h 已逐字节核对，与 native-dev.3 准备源码一致。
- 音频队列恢复 8 帧，取消强制 512 采样设备回调配置。
- 升级时迁移 Documents 已保留的 audio_maxqframes=32 回到 8，不受旧语言
  迁移标记影响，变更前备份为 prototype.pre-v3.toml。其他设置保留。
- 保留游戏图标、默认英文与 guest 内存后备修正。
- 启动日志加入包版本、渲染路径及配置位置，便于区分不同版本的记录。

这是恢复 native-dev.3 运行方式的回归修正版，不能声称解决了原先动画后黑屏、
杂音或完整可玩性。上版 GLSL 编译、阶段链接和 IPA 构建均通过，但实际设备
反馈证明这些检查不足以验证 Apple GPU 的完整绘制路径。

覆盖升级时保留 game/ 与 saves/，不必重新导入 14 个资源分卷，不要先卸载。
复测首先确认开场画面、声音与菜单是否恢复，再记录动画后的画面。
新 log.txt 开头应包含 build=5 renderer=native-dev.3。
