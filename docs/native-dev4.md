# native-dev.4 实机反馈修正

针对 2026-10-23 上传的日志与实机反馈：

- 使用原 Switch 移植仓库 `art/icon_prototype.jpg` 的游戏图标，固定提交与
  SHA-256，构建时生成完整 iPhone/iPad AppIcon 资源并用 actool 编译进 IPA。
- 默认游戏语言改为英文。升级首次启动将旧版 `user_language = 12` 改为 `1`，
  原配置备份为 `prototype.pre-v2.toml`，其余玩家配置保留。
  此包不声称包含中文翻译资源。
- 音频预生成队列从默认 8 帧增至 32 帧，设备回调请求设为 512 个采样。
  这是针对缓冲耗尽杂音的修正尝试；端点格式与每 10 秒缺帧数会写入日志，
  以便复测后区分缺帧与音频解码异常。
- 原生渲染器原先在不支持 geometry shader 的设备跳过矩形、四边形绘制。
  新路径保留原顶点/像素着色器，使用 TCS/TES 展开这些图元，避免最终合成
  直接因缺少 geometry shader 被跳过。保留深度格式的运行时能力检测。

升级时保留应用 Documents 内的 game、saves、分卷，不必重新导入资源。
优先复测同一开场动画结束后的实际游戏画面，随后测试暂停/返回游戏、对话与
背景音乐。请保留本次生成的 log.txt 与 engine.log。

编译、着色器验证与实际设备可玩性分别记录。未在 iPhone 实测前不能确认
黑屏或杂音已彻底消除；点精灵仍需要额外的 Apple 图元兼容实现。
