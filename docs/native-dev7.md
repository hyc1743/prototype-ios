# native-dev.7：中文资源与帧时间

这是待验证的候选版；编译成功不能代替实际游戏运行检查。

默认使用简体中文文本，保留英文语音。原资源包的 English 文本分支实际为巴西葡语，
只改语言 ID 无法切换英文。适配以文本键为依据，覆盖 2,951 项菜单/HUD 文本、
14,318 个对白字幕文件、143 个影片字幕文件和 45 个过场文件。
补丁中一个额外 PC 对白文件在此版资源中不存在，未强行加入。

玩家提供的 `CH` 是依赖不同 Windows 底包的差分补丁。
补齐完整中文文本后，转换器仅修改当前主机版的文本块和长度字段，
保留原生音频、场景与贴图数据，保留手柄图标和 `PrototypeBody360` 等字体名称。
中文字体补齐所需字形，未套用多兆字节的 PC 标题字体。
译者名单与原说明保留在安装包 `dm/chinese/CREDITS.txt`。

首次启动会在资源准备界面显示中文应用进度，生成独立中文资源视图和覆盖文件。
APFS 上克隆原文件以共享原有数据块，仅修改克隆归档的索引，使游戏优先读取中文覆盖。
修改前后检查原归档索引不变；音频文件保持原来的压缩/非压缩形式。
原有 RCF、存档不改写，不需要重下整个游戏资源包；首次转换需要额外存储空间。
已完成文件可在中断后复用，后续启动检查安装收据。

GPU 提交批次保持有上限，从 128 次绘制调整为 256 次，保留先前可游玩的后期合成修复。
同一测试源码的 macOS 观察中，每帧提交约从 33 次降为 16.5 次；
稳定场景的 300 帧观察段中，基线为 11.27–12.15 fps，新批次为 12.70 fps。
绘制负载略有差异，且测试使用 macOS 虚拟 GPU，不能当作 iPhone 帧率结论。
新增低频帧时间、等待与编译开销日志，用于后续实机定位。
